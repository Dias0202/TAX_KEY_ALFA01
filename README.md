# TaxKeyAlfa

TaxKeyAlfa is an interactive taxonomic key developed to facilitate the morphological identification of neotropical mosquito vectors of arboviruses. It enables rapid and structured identification while preserving data integrity by automating data storage and exportation.

## Features
- **Interactive Identification**: Navigate through subfamily, tribe, genus, and species keys with visual aids.
- **Biogeographic Data Input**: Register specimen collection details (park, date, collector, sampling point, strategy, etc.).
- **Automated Data Storage**: All records are automatically saved and exported in SQL and CSV formats.
- **User-Friendly Interface**: Built with Tkinter for an intuitive graphical user interface.

## Installation

### Prerequisites
Ensure you have Python 3.12 installed on your system.

### Clone the Repository
```bash
git clone https://github.com/yourusername/TaxKeyAlfa.git
cd TaxKeyAlfa
```

### Install Dependencies
```bash
pip install -r requirements.txt
```

## Usage
Run the main script to start the application:
```bash
python main.py
```

## Files and Directories
- **`main.py`** – Core script of the application.
- **`requirements.txt`** – List of required dependencies.
- **`ArboTeamPng.png` & `LogoFinal.png`** – Images required for the GUI.
- **`dados_mosquitos.xlsx`** – Excel file where mosquito identification data will be stored.
